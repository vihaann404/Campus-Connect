# CampusConnect

**CampusConnect** is a peer-to-peer student collaboration platform developed for **SYRUS 7.0**, addressing Sustainability Problem Statement 4.

The platform connects first-year engineering students with seniors to encourage mentorship, knowledge sharing, and sustainable resource utilization.

## Features
- Anonymous Q&A and senior mentorship
- Technical communities and discussions
- Hackathons, internships, and opportunities hub
- Academic resource exchange
- Search, upvotes, and content moderation

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Firebase
- **Database:** Cloud Firestore
- **Authentication:** Firebase Authentication
- **Hosting:** Firebase Hosting

## Sustainability Goals
- **SDG 4:** Quality Education
- **SDG 12:** Responsible Consumption and Production
